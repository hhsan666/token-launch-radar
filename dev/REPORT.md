## 推定価値のモデルの要約（peer-curve-3）

`implied = 10^(a + b·log10 TVL + sector) × momentum × runway`

- 規模曲線: トークン発行済みで時価総額が正の 128 件に、log 時価総額 ~ log TVL の最小二乗（a = 3.025, b = 0.522, R² 0.19）。b < 1 = TVL が大きいほど倍率が小さい。
- セクター補正: 同業の残差の平均を n/(n+k) で縮小。k は {0,1,2,4,8,16,32} から LOO 誤差が最小の 8。
- モメンタム: 7 日 TVL 変化 − 全体の中央値（−8.2%）、±30pt で上限、弾性 0.5。
- 稼働期間（トークン無しで追跡された日数）: 0.7 から 730 日で 1.0 まで対数曲線。不明は中間。
- 幅: 保留データの誤差の 25〜75 パーセンタイル（×0.32〜×3.31）。
- 保留データでの検証（LOO、128 件）: 誤差の中央値 ×3.26（単純な倍率 ×5.07、規模曲線のみ ×3.40、カテゴリ補正を加えると ×3.55 で悪化 → 不採用）。順位相関 0.44。
- 使っていないもの: 手数料・収益（スナップショットに無い）、ネットの最新情報。プロトコル名の特別扱いなし。
